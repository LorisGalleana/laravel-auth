# LARAVEL AUTH - Portfolio Management System

## Descrizione

**Laravel Auth** è un'applicazione sviluppata con **Laravel 10** per gestire un portfolio di progetti. Il sistema include funzionalità di autenticazione per separare gli utenti in due ambienti distinti: **Admin** (per gestire il portfolio) e **Guest** (per visualizzare i progetti). Nel corso delle lezioni successive, il progetto sarà arricchito di nuove funzionalità.

## Funzionalità

- **Autenticazione**:
  - Login per Admin e Guest.
  - Registrazione per gli utenti (Admin).
  - Separazione tra ambiente Admin (per gestione) e Guest (per visualizzazione).
- **Gestione del Portfolio**:
  - Admin può aggiungere, modificare ed eliminare progetti dal portfolio.
  - Guest può visualizzare i progetti nel portfolio.

## Tecnologie Utilizzate

- **Laravel 10**: Framework PHP per la gestione del backend.
- **Eloquent ORM**: Per l'interazione con il database.
- **Blade**: Motore di templating per la gestione delle view.
- **PHP**: Linguaggio di programmazione per il backend.
- **MySQL**: Database per la memorizzazione dei dati.
